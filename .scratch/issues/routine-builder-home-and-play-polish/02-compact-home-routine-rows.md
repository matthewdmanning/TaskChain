# 02 — Use compact action rows on Home

**What to build:** Present each Home routine as a compact row with its title and status-appropriate action on the same line. Hide the routine description on Home without removing it from the routine template. Put a Play icon at the right edge for routines that can be started and a Check icon in that position for completed scheduled occurrences.

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] Home does not display routine descriptions, while saved descriptions remain available elsewhere.
- [x] Each actionable routine shows its title and an accessible Play action aligned on the same row.
- [x] Each completed scheduled occurrence shows an accessible Check icon instead of Play.
- [x] The existing Scheduled, Manual, and Completed classification remains unchanged and every displayed routine still appears exactly once.
- [x] Empty sections and long routine titles remain usable without overlapping or clipping the action icon.
